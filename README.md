# Osnhape_to_USD
Quick pipeline to take your onshape models to IsaacLab ready to train USD (in Ubuntu)

Takes in the required paths, keys and  names then generates the robot URDF, USD and a starter policy training file. It will also allow you to view the generated URDF in a browser to confirm everything is correct.

This is using onshape to robot by Rhoban(https://github.com/rhoban/onshape-to-robot)

Each step of the pipeline is configurable so you can cut it off at any point. 

I have found that this streamlined creation of my robots, and allowed me to focus on design changes rather than worrying about command prompts.
